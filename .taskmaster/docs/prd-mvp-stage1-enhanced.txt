# ShopValue MVP SaaS Platform - Enhanced Product Requirements Document
## Stage 1: Revenue-Generating MVP for Solo Development (8-12 weeks)

### 1. EXECUTIVE SUMMARY

**Vision:** Transform ShopValue from a basic price tracking tool into a fully automated, revenue-generating SaaS platform that serves Romanian consumers with reliable price tracking and alerts while minimizing manual intervention for the solo developer.

**Success Metrics:**
- €2-5K Monthly Recurring Revenue (MRR) by month 6
- 1,000+ registered users
- 500+ tracked products across platform
- 15% trial-to-paid conversion rate
- 5% monthly churn rate
- <2 hours/week manual maintenance time

**Target Market:** Romanian consumers aged 25-45 who shop online regularly and want to save money on purchases.

**Solo Development Principles:**
- Maximum automation using managed services
- Zero manual user management via webhooks
- Automated billing and subscription management
- Automated error monitoring and alerting
- Automated deployment and scaling

### 2.3 Enhanced Product Tracking System
**Requirement:** Sophisticated product tracking with automated data management

**Core Functionality:**
- **One-Click Product Addition:** URL paste → automatic product detection → tracking setup
- **Smart Product Detection:** Extract title, price, image, brand automatically
- **Duplicate Prevention:** Check existing products before adding
- **Bulk Management:** Mass actions for tracked products
- **Categories:** Auto-categorize products using AI
- **Price History:** Store and visualize price changes over time

**Database Schema Optimization:**
```typescript
interface Product {
  _id: ObjectId;
  url: string;                    // Unique index
  title: string;                  // Text index for search
  brand: string;                  // Index for filtering
  category: string;               // Index for grouping
  image: string;
  currentPrice: number;           // Index for price queries
  originalPrice: number;
  discount: number;
  availability: 'in_stock' | 'out_of_stock' | 'limited';
  lastChecked: Date;             // Index for stale data cleanup
  priceHistory: PricePoint[];    // Separate collection for better performance
  metadata: {
    description?: string;
    rating?: number;
    reviewCount?: number;
    seller?: string;
  };
  tracking: {
    totalTrackers: number;       // Count of users tracking this product
    isActive: boolean;           // For cleanup of untracked products
  };
  createdAt: Date;
  updatedAt: Date;
}

interface UserProductTracking {
  _id: ObjectId;
  userId: string;                // Index - Clerk user ID
  productId: ObjectId;           // Index - Reference to Product
  priceAlert: {
    enabled: boolean;
    threshold: number;           // Alert when price drops below this
    thresholdType: 'fixed' | 'percentage';
  };
  notifications: {
    lastAlertSent: Date;
    alertsSent: number;
  };
  addedAt: Date;
  isActive: boolean;             // For soft deletion
}

interface PriceHistory {
  _id: ObjectId;
  productId: ObjectId;           // Index
  price: number;
  timestamp: Date;               // TTL index for automatic cleanup
  source: 'scraper' | 'manual';
}
```

**Automated Data Management:**
- **TTL Indexes:** Automatic cleanup of old price history (90 days)
- **Unused Product Cleanup:** Remove products with no active trackers
- **Performance Monitoring:** Automatic query optimization alerts
