# ShopValue MVP SaaS Platform - Enhanced Product Requirements Document
## Stage 1: Revenue-Generating MVP for Solo Development (8-12 weeks)

### 1. EXECUTIVE SUMMARY

**Vision:** Transform ShopValue from a basic price tracking tool into a fully automated, revenue-generating SaaS platform that serves Romanian consumers with reliable price tracking and alerts while minimizing manual intervention for the solo developer.

**Success Metrics:**
- €2-5K Monthly Recurring Revenue (MRR) by month 6
- 1,000+ registered users
- 500+ tracked products across platform
- 15% trial-to-paid conversion rate
- 5% monthly churn rate
- <2 hours/week manual maintenance time

**Target Market:** Romanian consumers aged 25-45 who shop online regularly and want to save money on purchases.

**Solo Development Principles:**
- Maximum automation using managed services
- Zero manual user management via webhooks
- Automated billing and subscription management
- Automated error monitoring and alerting
- Automated deployment and scaling

**Core Functionality:**

**Database Schema Optimization:**
```typescript
interface Product {
  _id: ObjectId;
  url: string;                    // Unique index
  title: string;                  // Text index for search
  brand: string;                  // Index for filtering
  category: string;               // Auto-categorized, indexed
  image: string;
  currentPrice: number;           // Index for price queries
  originalPrice: number;
  currency: 'RON' | 'EUR';
  discount: number;
  availability: 'in_stock' | 'out_of_stock' | 'limited';
  lastChecked: Date;             // Index for stale data cleanup
  checkFrequency: number;        // Hours between checks
  metadata: {
    description?: string;
    rating?: number;
    reviewCount?: number;
    seller?: string;
    sku?: string;
  };
  tracking: {
    totalTrackers: number;       // Count of users tracking
    isActive: boolean;           // For cleanup
    popularity: number;          // Tracking frequency
  };
  scraping: {
    selector: string;            // Price element selector
    lastSuccessful: Date;
    failureCount: number;
    isBlocked: boolean;
  };
  createdAt: Date;
  updatedAt: Date;
}

interface UserProductTracking {
  _id: ObjectId;
  userId: string;                // Clerk user ID, indexed
  productId: ObjectId;           // Product reference, indexed
  priceAlert: {
    enabled: boolean;
    threshold: number;           // Alert below this price
    thresholdType: 'fixed' | 'percentage';
    lastTriggered?: Date;
  };
  notifications: {
    lastAlertSent?: Date;
    alertsSent: number;
    preferences: {
      email: boolean;
      push: boolean;
      frequency: 'immediate' | 'daily' | 'weekly';
    };
  };
  customName?: string;           // User's custom product name
  tags?: string[];               // User's custom tags
  addedAt: Date;
  isActive: boolean;
}

interface PriceHistory {
  _id: ObjectId;
  productId: ObjectId;           // Indexed
  price: number;
  timestamp: Date;               // TTL index (90 days)
  source: 'scraper' | 'manual' | 'api';
  confidence: number;            // Scraping confidence score
}
```

**Automated Data Management:**
- TTL indexes for automatic price history cleanup (90 days retention)
- Scheduled cleanup of products with zero active trackers
- Automatic product deactivation for repeatedly failed scraping
- Performance monitoring with automatic index optimization alerts

### 2.4 Automated Notification System (Resend Integration)

**Technical Implementation:**
```typescript

// Email templates stored in /emails directory as React components
```

**Notification Types with Automated Triggers:**
- **Price Drop Alerts:** Triggered by price comparison in cron jobs
- **Back-in-Stock Notifications:** Triggered when availability changes to in_stock
- **Welcome Email Series:** Triggered by Clerk user.created webhook
- **Subscription Confirmations:** Triggered by Stripe webhooks
- **Weekly Deal Roundups:** Triggered by weekly cron job
- **Billing Notifications:** Triggered by Stripe payment events
- **Trial Expiration Warnings:** Triggered 3 days before trial ends

**Email Queue System with Bull/Redis:**
```typescript
interface EmailJob {
  userId: string;
  template: 'price_alert' | 'welcome' | 'trial_ending' | 'weekly_digest' | 'billing_failed';
  data: any;
  scheduledFor?: Date;
  priority: 'high' | 'normal' | 'low';
  retryCount: number;
}

// Queue configuration with Upstash Redis
const emailQueue = new Queue('email-processing', {
  redis: upstashRedis,
  defaultJobOptions: {
    removeOnComplete: 100,
    removeOnFail: 50,
    attempts: 3,
    backoff: {
      type: 'exponential',
      delay: 5000
    }
  }
});
```

**Required Email Templates:**
- Welcome email with onboarding checklist
- Price alert with product details and purchase links
- Weekly digest with best deals and price trends
- Subscription confirmation with billing details
- Payment failure notification with retry link
- Trial expiration warning with upgrade prompts
- Account deletion confirmation

## 3. PERFORMANCE & CACHING (Upstash Redis)

### 3.1 Caching Strategy
**Requirement:** Sub-200ms API response times with intelligent caching

**Implementation:**
```typescript
npm install @upstash/redis
// Automatic caching layers:
const cacheConfig = {
  productSearch: { ttl: 3600 },      // 1 hour
  userSubscription: { ttl: 1800 },   // 30 minutes  
  priceHistory: { ttl: 86400 },      // 24 hours
  popularProducts: { ttl: 21600 },   // 6 hours
  categoryData: { ttl: 43200 }       // 12 hours
};
```

**Cache Invalidation Strategy:**
- Product price updates → Clear product and search caches
- User subscription changes → Clear user cache
- New product additions → Clear category and popular product caches
- Bulk price updates → Selective cache warming

### 3.2 Database Optimization
**Required MongoDB Indexes:**
```typescript
const mongoIndexes = {
  products: [
    { url: 1 },                           // Unique
    { brand: 1, category: 1 },            // Compound filtering
    { currentPrice: 1, brand: 1 },        // Price range queries
    { title: "text", "metadata.description": "text" }, // Search
    { lastChecked: 1 },                   // Stale data cleanup
    { "tracking.isActive": 1, "tracking.popularity": -1 } // Active products
  ],
  users: [
    { clerkId: 1 },                       // Primary lookup
    { email: 1 },                         // Email searches
    { stripeCustomerId: 1 },              // Stripe integration
    { subscriptionTier: 1, subscriptionStatus: 1 } // Subscription queries
  ],
  userProductTracking: [
    { userId: 1, isActive: 1 },           // User's products
    { productId: 1, isActive: 1 },        // Product trackers
    { userId: 1, productId: 1 },          // Unique constraint
    { "priceAlert.enabled": 1, "priceAlert.threshold": 1 } // Alert processing
  ],
  priceHistory: [
    { productId: 1, timestamp: -1 },      // Product timeline
    { timestamp: 1 }                      // TTL cleanup
  ]
};
```
